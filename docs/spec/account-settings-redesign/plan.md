# Account settings redesign

1. Audit the existing settings components, navigation, requirements, and design.
2. Build a full-height settings workspace with an edge-to-edge desktop sidebar
   and mobile modal drawer, without a site header, footer, or outer frame.
3. Restyle profile/session/deletion sections and all existing states while
   preserving API behavior and confirmation accessibility.
4. Verify frontend checks, existing authentication flows, both themes, and
   responsive layouts; update design documentation and archive these files.

All steps are complete, including the final sidebar identity cleanup after
deletion. See [spec.md](spec.md) for acceptance criteria and
[verification.md](verification.md) for results and screenshot evidence.
