# Frontend and backend CI checklist

- [x] Inspect requirements, current main, application scripts and test setup.
- [x] Create `feature/frontend-backend-ci` from clean current main.
- [x] Record user-supplied design, spec and implementation plan.
- [x] Implement and verify fail-closed CI helpers and pinned workflows.
- [x] Configure Maven wrapper, formatting, Failsafe, Testcontainers, coverage and static analysis.
- [x] Validate backend Docker targets and dependency/image scans.
- [x] Verify frontend install, static checks, tests and production build.
- [x] Document required checks and actual verification evidence.
- [x] Complete independent code review and resolve material findings.
- [x] Push feature PR and verify hosted checks.
- [x] Complete acceptance criteria and archive task files before readiness.
