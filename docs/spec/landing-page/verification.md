dashboard, API, schema, hosting, or deployment behavior changed.

## Independent review and regression fixes

The authorized read-only reviewer completed code and visual review and
re-reviewed the fixes. Final result: no unresolved Critical, Important, or Minor
findings; no deferred findings.

- Important: changing light duration preserved elapsed time and skipped cycles.
  Restart at the dim boundary; browser regression verifies three fresh randomized
  cycles with no timer/control.
- Minor: CSS breakpoint hiding can blur focus before the media event. Preserve
  focus memory only across that hiding event; clear it on ordinary blur.
  Unit/browser regressions cover desktop links and open/closed Menu triggers.
- Important: installed Motion's reduced-motion hook captured an initial snapshot.
  Browser RED reproduced stale values both ways. A live media-query subscription
  now completes active reveals and commits initial static text. Tightened browser
  regressions verify prompt cancellation and no re-hiding when motion is enabled.
- Footer typography: relaxed tracking, 1.3 line height, and padded masks prevent
  crowded/clipped glyphs. Latest user steering centers the wordmark horizontally.
